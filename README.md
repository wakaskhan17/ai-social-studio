# AI Social Studio — public information pages

Static GitHub Pages website for app information, Terms of Service and Privacy Policy.

## Before publishing
- Replace `[REPLACE WITH YOUR SUPPORT EMAIL BEFORE PUBLISHING]` in all three HTML files with an email you are willing to display publicly.
- Read the Terms and Privacy Policy carefully and edit anything that doesn't describe your actual software and data handling.
- The policies are editable starter drafts, not legal advice.

## Publish on GitHub Pages
1. Create a **public** repository called `ai-social-studio` on GitHub.
2. Upload the contents of this folder to the root of the repository (not inside an extra subfolder).
3. Open repository **Settings** > **Pages**.
4. Set **Build and deployment** source to **Deploy from a branch**, branch **main**, folder **/(root)**. Save.
5. Wait for Pages to deploy and open `https://YOUR-GITHUB-USERNAME.github.io/ai-social-studio/`.

Links for TikTok developer form:
- Web/Desktop URL: `https://YOUR-GITHUB-USERNAME.github.io/ai-social-studio/`
- Terms: `https://YOUR-GITHUB-USERNAME.github.io/ai-social-studio/terms.html`
- Privacy: `https://YOUR-GITHUB-USERNAME.github.io/ai-social-studio/privacy.html`

These static pages do NOT provide a public API, OAuth callback or remote ChatGPT connection. They do not automatically satisfy TikTok's domain verification or app-review requirements.
