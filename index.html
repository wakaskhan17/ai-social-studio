AI Social Studio

AI Social Studio is a desktop application in development for preparing, organising and scheduling social-media content. Its planned features include image-carousel preparation, caption and hashtag drafting, and optional TikTok publishing via TikTok's official APIs where authorized and approved.

How it works

A user creates or supplies content, reviews the post details and chooses when to publish. Once enabled, TikTok integration will require the account holder's consent and TikTok's applicable permissions. Automated public publishing is not yet available in this prototype.

Current status

The initial local prototype supports saving draft post details. Image generation, direct publishing, and scheduled execution are under development. This public website provides basic app information and policies; it is not a hosted application dashboard.
